# Smart Meter Texas v0.2.0

First public source release of Smart Meter Texas, a self-hosted electricity usage monitoring and analytics dashboard.

## Highlights

- 15-minute and daily electricity usage, dashboard KPIs, usage charts and seven-day heatmap.
- Scheduled incremental synchronization, manual catch-up, DST-aware data health checks and gap repair.
- Electricity cost estimates using date-ranged rates, monthly forecasting and historical charts.
- Open-Meteo weather correlation and inferred HVAC-related energy analysis.
- Modified Z-score anomaly detection and optional, opt-in Discord notifications.
- Responsive light/dark interface, with configurable application settings stored in SQLite.

## Security and operations

- Dashboard and API HTTP Basic authentication are enabled by default. Applications behind a fully protected Cloudflare Access gateway may opt to delegate authentication using `SMT_WEB_AUTH_ENABLED=false`; this disables all application-level authentication and requires protecting every route, including `/api/*`.
- Docker publishes port 8090 on `127.0.0.1` by default. Do not expose the application directly to the internet.
- Meter usage history, account credentials, backups and Discord webhook values are private data; keep `.env`, `./data` and `./logs` out of public repositories and backups appropriately secured.
- Raw upstream response retention is disabled by default.
- The tagged source snapshot passed the repository CI suite: Python tests, frontend build, Docker authentication/health smoke test and Gitleaks history scan.
