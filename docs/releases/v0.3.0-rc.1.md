# Smart Meter Texas v0.3.0-rc.1

**Prerelease – staging evaluation only. Do not treat as a validated production release.**

## Highlights

- Installable progressive web app metadata for Android and iOS Home Screen.
- Standalone mode, 192px and 512px PNG app icons, and Apple touch metadata.
- Small Service Worker designed to avoid caching API data, HTML navigation or authentication responses.
- Update detection and manual reload prompt (requires device/browser testing).
- Explicit FastAPI static routes for PWA files with HTTP Basic authentication protection.
- Fixed user-controlled filesystem path handling reported by GitHub CodeQL.
- Automated PWA metadata checks and backend static-file security regressions.

## Known limitations

- Not an offline energy dashboard. An authenticated network connection remains required.
- Cloudflare Access can behave differently in installed app contexts; login, reauthentication and cookies require real mobile testing.
- Server responses currently carry `Cache-Control: no-store`, so Service Worker static caching may effectively be disabled. Privacy is prioritized over offline use.
- This prerelease does not change the SMT website endpoint integration or provider access authorization.

## Upgrade / rollback

Use the immutable release tag after publication, not a moving branch. Deploy to a staging instance with **synthetic data only**. Back up `.env`, SQLite and private state before any production rollout. For rollback, return to `v0.2.0` source/image and compatible persisted state.

This is an unofficial project; the code's publication does not provide authorization for automated extraction from Smart Meter Texas. Read the current terms and arrange the provider authorization that applies to your deployment.
